# Карта проекта

## Назначение
Личная заметка по долгам для GitHub Pages. При первом осмотре каталог был пуст,
Git-репозиторий и удалённый адрес отсутствовали.

## Структура и точки входа
- `index.html` — русскоязычный интерфейс, вкладки, таблица, форма входа и диалоги.
- `styles.css` — адаптивное оформление с БЭМ-классами; `favicon.svg` — иконка.
- `app.js` — ES-модуль интерфейса, обработчики форм, вход, экспорт/импорт JSON.
- `config.js` — экспорт `config` с публичными параметрами Supabase; пока пустые.
- `core.mjs` — валидация, разбор денежных сумм, форматирование, формат копии.
- `storage.mjs` — `localRepository` и `cloudRepository`.
- `supabase.sql` — таблица `debts`, индекс и RLS по `auth.uid() = user_id`.
- `scripts/serve.mjs` — локальный HTTP-сервер, только разрешённые статические файлы.
- `tests/debt.test.mjs` — 17 тестов логики и адаптеров, облачный API имитируется.
- `package.json` — команды без внешних npm-зависимостей.
- `.nojekyll` — отключает Jekyll при публикации корня на GitHub Pages.
- `.gitignore` — исключает кэш, зависимости, журналы и `.env`.
- `README.md` — запуск, подключение Supabase, публикация репозитория `debt`.

## Данные и ограничения
- Пустой `config.js`: localStorage с ключом `debt.records.v1` (`core.mjs`).
- Настроенный `config.js`: вход по почте/паролю через Supabase, только облачная база.
- При ошибках облака перехода к локальной записи нет (`app.js`).
- SDK Supabase 2.118.0 загружается с jsDelivr только в облачном режиме (`app.js`).
- Записи хранят суммы целым числом копеек; итоги считаются через BigInt (`core.mjs`, `app.js`).
- Лимит клиента — 10 000 записей; импорт до 10 МБ (`core.mjs`, `app.js`).
- JSON-копия содержит обе вкладки, без `user_id`; импорт добавляет новые ID (`storage.mjs`).
- Облако читается страницами по 500 строк; новые данные загружаются по кнопке
  и при возвращении на страницу, без Realtime (`storage.mjs`, `app.js`).
- Одновременное изменение одной записи: последнее сохранение побеждает (`storage.mjs`).
- Относительные пути позволяют размещать сайт в `/debt/` (`index.html`, импорты JS).

## Подтверждённые проверки
- `npm.cmd run check` — синтаксис модулей и 17 проходящих тестов.
- `npm.cmd start` / `node scripts/serve.mjs` — http://127.0.0.1:4173.
- Проверены HTTP 200 для семи статических ресурсов и HTTP 404 для трёх закрытых путей.
- Проверены соответствие ID из `app.js` разметке и отсутствие дублей ID.
- Публичный URL закреплённой версии SDK вернул HTTP 200.
- Визуальная проверка не выполнялась: подключённых браузеров в среде нет.
- База, реальный вход, RLS и обмен между устройствами не проверялись:
  проект Supabase и доступ к GitHub ещё не подключены. Сайт не опубликован.
